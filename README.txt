# Математическая битва — 9 класс

Откройте `index.html` в браузере.

## Что есть в игре
- 20 карточек;
- красная и синяя команды;
- ход по очереди;
- плавное переворачивание карточки;
- 2 минуты после выбора карточки;
- кнопка «Проверить»;
- «Правильно» / «Неправильно»;
- начисление баллов;
- БАНКРОТ — обнуление баллов;
- ОБМЕН БАЛЛАМИ;
- ДВОЙНОЙ БАЛЛ;
- КРАЖА БАЛЛОВ;
- автоматическое переключение команды;
- кнопка «Новая игра».

## Как изменить вопросы
Откройте `script.js`. В начале файла находится массив `cardsData`.
У каждой обычной карточки есть:
- `points` — количество баллов;
- `question` — вопрос;
- `answer` — правильный ответ (для отображения учителю).

Специальные карточки имеют `type`:
- `bankrupt`
- `swap`
- `double`
- `steal`

Таймер сейчас установлен на 120 секунд.
